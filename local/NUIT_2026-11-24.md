# Nuit du 24/11/2026 — état du démarrage (branche `int-local`)

Aucune donnée du jeu ici : code, comptes et formes d'appels seulement. Machine : RTX 4080 Laptop (NVIDIA, sous-groupes
32), CPU Intel (pas de SSE4a/CLZERO/MONITORX), `LEONIDA_D3D12=vulkan`.

## Résumé

- **Le jeu tourne à ~60 images/s** (8 000+ `PresentX` en 2-3 min), toutes les command lists sont **exécutées sur le
  GPU**, sans échec de soumission. La chaîne d'affichage est vérifiée de bout en bout (`LEONIDA_DIAG_CLEAR=1` : la
  fenêtre devient magenta).
- **L'image reste noire** : le jeu ne dessine encore qu'un compositeur (3 triangles plein écran) et un quad texturé
  par image. Les lectures disque s'arrêtent vers 27-30 s (≈3 Go lus) : le démarrage attend quelque chose.
- **Pas de son** : le jeu n'importe aucune API audio PC ; tout passe par le matériel audio de la console (`AcpHal`,
  `xapu`, `chad`), que les shims acceptent sans rien produire.

## Ce qui a été corrigé (commits locaux)

| Problème | Effet | Correction |
|---|---|---|
| Slots console 50-54 de la command list (`OMSetRenderTargets`, `Clear*View`) | handles CPU du heap placé par le titre non traduits → liste invalide → **chaque image refusée** | traduction des handles comme les slots 17-24 du device |
| Draw avec un pipeline stub (`LEONIDA_STUB_PIPELINES`) | invalidait la liste entière | le draw est ignoré (D3D-482) |
| **Queue slot 35** | c'est la soumission des command lists du titre ; il était ignoré → **rien n'était exécuté** | `(count, lists)` reconnu et exécuté sur la vraie queue |
| Buffer de 182 Mo placé par le titre (device slot 133) | pages `xmem` engagées au premier accès → import Vulkan refusé → vertex buffers introuvables | engagement des vues avant l'import, import différé si pas encore mappé |
| Mémoire titre write-combined (`PAGE_WRITECOMBINE`) | second buffer placé non importable | `xmem` ne pose plus de modificateur de cache |
| **CLZERO sur CPU Intel** | 1 trap par ligne de 64 octets → **~5 s par image** | la boucle `clzero/add/cmp/jb` est exécutée d'un bloc dans le gestionnaire → ~60 images/s |
| Device slot 81 | `E_NOTIMPL` à chaque image | routé vers `GetFrameStatisticsX` |
| Device slot 57 = `DeserializeGraphicsPipelineStateX` | 10 241 pipelines de la bibliothèque refusés | pipeline stub, puis **vrai pipeline au premier draw** (VS/PS retrouvés par l'empreinte HASH, input layout et blend décodés, formats pris sur les cibles liées) |
| Shaders absents du corpus | 1 pipeline par image ignoré | `LEONIDA_CAPTURE_SHADERS` capture le conteneur manquant ; `local/scripts/capture_loop.ps1` le traduit et relance |

## Mesures utiles

- Slot 57 : `(desc, IID_ID3D12PipelineState, out)` ; la description est celle de l'exemple public Microsoft
  `Xbox-GDK-Samples/Samples/Graphics/HlslCompile/AcoPipelineState.cpp` : root signature, packet + taille, métadonnées
  + taille, puis `{instructions, taille, métadonnées, taille}` pour PS, VS, GS, ES, HS, LS, FS.
- Packet (388 octets) : registres RDNA2. `CB_BLEND0..7_CONTROL` à +0xD0, `CB_TARGET_MASK` à +0xF0,
  `DB_DEPTH_CONTROL` à +0xA0, `DB_STENCILREFMASK(_BF)` à +0xC0. Les autres tailles (380-520) ne sont pas vérifiées.
- Métadonnées du pipeline = input layout : tête de 0x50 octets (nombre d'éléments à +0x4C), puis par élément
  `{u32 longueur du nom avec NUL, nom, index, format DXGI, slot, offset, classe, pas}`.
- Queue (disposition « newer ») : PresentX 32, soumission 35 `(count, lists)`.
- Les 42 shaders compute demandés au slot 67 sont dans la bibliothèque : 38 traduits, 4 refusés (registre
  « thread-group size » non géré) → stubs.

   le titre n'écrit jamais. Hypothèse forte : c'est la texture du quad affiché à chaque image (écran de démarrage) →
   transparent → noir. Il faut recopier (et dé-tuiler, `tools/amd_swizzle.py`) la mémoire du titre dans la texture
   avant chaque soumission, ou l'importer.
2. **Ce qu'attend le démarrage à ~27 s** : seul appel D3D12 en échec pendant le blocage = slot 57 (corrigé) ; les
   threads sont en attente dans `ntdll` (`local/scripts/sample_threads.ps1` lit leurs piles). Piste : l'audio
   (dernier événement de démarrage = `XApuConnect`/`XDspConnect`), puis l'entrée (écran « appuyez sur… »
   invisible, `LEONIDA_KEYBOARD_PAD`).
3. Slot 57 pour les pipelines mesh (GS) et les autres tailles de packet ; le cull mode n'est pas décodé.
4. Son : émuler `xapu` (décodage Opus/XMA) + `chad`/`AcpHal` (mixage) vers WASAPI ; formats de commandes inconnus.
